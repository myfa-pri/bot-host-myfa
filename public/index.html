Getting Started

Deploy your Telegram bot to MyFa Host in under 2 minutes — no server setup required. Follow these steps:

  1. Open Telegram and search for @BotFather
  2. Send /newbot and follow the prompts to name your bot
  3. Copy the HTTP API Token you receive (format: 123456:ABCDEFghij…)
  4. In MyFa Host, tap + (Create tab), paste the token, and press Launch Bot
  5. Your bot dashboard opens — go to the Commands tab
  6. Tap + to create your first command (e.g. start)
  7. Write your code in the editor and press Save
  8. Tap Start on the dashboard home — your bot is now live!
No coding experience required for basic bots. Use our pre-built Templates to get a fully working bot with one tap.

Commands API Reference

Every command has access to these built-in globals. You can use them directly without importing anything:

ctx // Full Telegraf context — all Telegram API methods
user // { id, first_name, last_name, username, language_code }
chat // { id, type, title, username } — current chat info
message // Full message object { text, photo, document, … }
env // Your environment variables (env.MY_KEY)
Bot.runCommand(cmd) // Trigger another command by name
Bot.sendMessage(text) // Send a plain text message to current chat
fetch(url, opts) // Full HTTP fetch — await supported

Common Examples:

// Basic reply
ctx.reply('Hello, ' + user.first_name + '! ');

// Send formatted HTML message
ctx.replyWithHTML('<b>Bold</b> and <i>italic</i> and <code>code</code>');

// Reply with Markdown
ctx.replyWithMarkdown('*Bold* and _italic_ and `code`');

// Send photo by URL
ctx.replyWithPhoto('https://example.com/image.jpg', {caption:'My photo'});

// Send document
ctx.replyWithDocument({url:'https://example.com/file.pdf'});

// Inline keyboard buttons
ctx.reply('Choose an option:', {reply_markup:{inline_keyboard:[[
  {text:'fa-check Yes',callback_data:'yes'},
  {text:'fa-times No',callback_data:'no'}
]]}});

// Reply keyboard (persistent buttons)
ctx.reply('Pick one:', {reply_markup:{keyboard:[['fa-home Home','fa-info About']],resize_keyboard:true,one_time_keyboard:true}});

// Read env variable
ctx.reply('API Key starts with: ' + env.MY_API_KEY.slice(0,4) + '…');
Async/await is supported. You can use await fetch(), await Bot.runCommand(), and any async operation directly in your command code.

Callback & Button Handling

When a user taps an inline button with callback_data, the platform routes it to the command matching that data string. Name your command the same as the callback_data value:

// In your /start command — send a button with callback_data 'help':
ctx.reply('Hello! What do you need?', {reply_markup:{inline_keyboard:[[
  {text:'fa-book Help', callback_data:'help'},
  {text:'fa-info About', callback_data:'about'}
]]}});

// Create a command named exactly 'help' — it runs when button is tapped:
ctx.answerCbQuery(); // REQUIRED: acknowledge the button tap
ctx.reply('fa-book Here is the help menu…');

// Read the callback data value:
const data = ctx.callbackQuery?.data; // e.g. 'help'
const from = ctx.callbackQuery?.from; // user who tapped
Always call ctx.answerCbQuery() at the start of any callback command to prevent the "loading" spinner in Telegram.

HTTP Requests & External APIs

Use the built-in fetch() to call any external API — crypto prices, weather, AI models, databases, and more:

// GET request — fetch crypto price
const res = await fetch('https://api.coinbase.com/v2/prices/BTC-USD/spot');
const data = await res.json();
ctx.reply(' Bitcoin: $' + data.data.amount);

// POST request — send data to an API
const r = await fetch('https://your-api.com/endpoint', {
  method: 'POST',
  headers: {'Content-Type':'application/json', 'Authorization':'Bearer '+env.API_TOKEN},
  body: JSON.stringify({user: user.id, action:'register'})
});
const result = await r.json();
ctx.reply(result.success ? 'fa-check Done!' : 'fa-times Failed: ' + result.error);

// Call OpenAI GPT (use env.OPENAI_KEY)
const ai = await fetch('https://api.openai.com/v1/chat/completions', {
  method:'POST', headers:{'Authorization':'Bearer '+env.OPENAI_KEY,'Content-Type':'application/json'},
  body:JSON.stringify({model:'gpt-4o-mini',messages:[{role:'user',content:message.text}]})
}).then(r=>r.json());
ctx.reply(ai.choices[0].message.content);

Telegram Mini App Pages

Build full-featured Telegram Mini Apps using HTML commands. MyFa Host auto-injects the Telegram WebApp SDK, so you get access to user data, theme colors, and all WebApp APIs out of the box.

How to create a Mini App page:
  1. Open a bot dashboard → Commands tab → tap +
  2. Set language to HTML Page in the top selector
  3. Write your full HTML/CSS/JS page
  4. Save — your page is live at /api/mini/<botId>/<commandName>
  5. Use the Preview button to test instantly

Open the Mini App from a bot command:

// In your /start command — open a mini app page named 'home':
ctx.reply('Open my app ', {reply_markup:{inline_keyboard:[[
  {text:' Open App', web_app:{url: env.HOST_URL+'/api/mini/'+env.BOT_ID+'/home'}}
]]}});

Inside your HTML page — use Telegram WebApp APIs:

// Telegram WebApp is auto-available
const tg = window.Telegram.WebApp;
tg.ready(); // Always call this first
tg.expand(); // Full-screen mode

// Get user info
const user = tg.initDataUnsafe.user;
document.getElementById('name').innerText = user.first_name;

// Use Telegram theme colors
document.body.style.background = tg.themeParams.bg_color;
document.body.style.color = tg.themeParams.text_color;

// Navigate to another HTML command page
miniApp.go('about'); // goes to /api/mini/<botId>/about

// Close the mini app
tg.close();

// Send data back to the bot
tg.sendData(JSON.stringify({action:'purchase', item:'gold'}));
miniApp.go('page') is a helper that navigates to another HTML command on the same bot. It preserves the bot context automatically.

Environment Variables

Environment variables let you store sensitive data (API keys, tokens, config) securely outside your code. Access any variable in commands using env.VARIABLE_NAME.

System Variables (Auto-Set):
HOST_URLYour deployment base URL — used for API callbacks and webhooks. Set via Auto-Set button.
BOT_IDYour bot's unique ID on this platform. Required for referral system and mini app URLs.
BOT_USERNAMEYour bot's Telegram username (without @). Used to generate referral invite links.
ADMIN_IDSComma-separated list of Telegram user IDs who have admin access. Example: 123456,789012
CHANNEL_IDTelegram channel ID for mandatory join check. Format: -100xxxxxxxxxx
POINTS_PER_REFERRALPoints awarded per successful referral (Refer & Earn template). Default: 10
// Examples of using env vars in commands:
ctx.reply('Your plan: ' + env.USER_PLAN);
const data = await fetch(env.HOST_URL + '/api/global-stats').then(r=>r.json());
const isAdmin = env.ADMIN_IDS.split(',').includes(String(user.id));
if (!isAdmin) return ctx.reply('fa-times Admins only!');
Never hardcode API keys in command code. Always use env variables — they are encrypted and never exposed in the editor or backups.

Advanced Features

Folder System

Organize your commands into folders. Tap the + Folder button in the Commands tab to create a folder, then assign commands to it using the editor's Folder setting. Filter commands by folder using the tabs at the top of the Commands list.

Auto-Retry

Set an auto-retry interval (in seconds) for a command. If the command fails or crashes, MyFa Host will automatically re-run it after the set interval. Useful for scheduled tasks and polling jobs. Default is 600 seconds (10 minutes). Set to 0 to disable.

Command Aliases

Give a command multiple trigger names. For example, a command named help with aliases h, ayuda, hilfe will respond to /help, /h, /ayuda, and /hilfe.

Inter-Command Calls

Call other commands from within a command using Bot.runCommand('commandName'). This is useful for shared logic, middleware patterns, and breaking large bots into modular pieces.

// Check admin in a shared 'check_admin' command, then call it:
await Bot.runCommand('check_admin'); // runs that command first
ctx.reply('Admin confirmed, proceeding…');

Analytics & Logs

The Analytics tab shows message volume, unique users, uptime, and error count for your bot. The Logs section shows the 50 most recent events including errors and command executions. Use this to debug issues and monitor bot health in real time.

Backup & Restore

Export your entire bot as a JSON backup or ZIP archive (System tab). The ZIP includes all command files organized by language extension (.js, .py, .sh, .html). Restore by uploading a JSON backup — all commands and settings are restored instantly.

Refer & Earn System

The Refer & Earn template creates a complete points-based referral system for your bot. Users earn points for inviting friends. Here's how to set it up:

  1. Go to Templates → Full Project → install Refer & Earn
  2. Set BOT_USERNAME env var to your bot's @username (without @)
  3. Set ADMIN_IDS to your Telegram user ID
  4. Optionally set POINTS_PER_REFERRAL (default: 10 points per invite)
  5. Start the bot — users can now use /refer to get their invite link
  6. When a new user joins via the link, points are automatically credited
  7. Use /refer_admin to see all user stats (admin only)
// The template generates referral links like:
https://t.me/YourBot?start=ref_123456789

// Users check their points with /points, share with /refer
